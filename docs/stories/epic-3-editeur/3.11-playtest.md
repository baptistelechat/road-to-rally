# Story 3.11 : Playtest de passage

**Statut : à faire**

## Objectif

Trancher le critère de l'epic : **« un ami crée une spéciale sans ton aide ».** Story ajoutée au découpage initial, sur le modèle des stories 1.10 et 2.9.

## Vérifié sans toi

- [ ] Parcours complet sur le build de production : recherche d'un lieu, tracé, garde-fous, génération, volant, retour à l'éditeur.
- [ ] Réouverture du même tracé sans aucune requête.
- [ ] Les textes d'erreur des services (BRouter, IGN, Overpass, géocodage) sont tous en français et proposent une suite.
- [ ] Le circuit, `road`, `mountain` et l'import d'un GPX se comportent comme à la fin de l'epic 2.
- [ ] `pnpm lint` et `pnpm build` passent. `pnpm check:determinism` seulement avec l'accord de Baptiste.

## Protocole de playtest

1. **Baptiste d'abord :** créer trois spéciales sur des routes qu'il connaît, dont une en montagne et une sur une petite route. Corriger ce qui gêne.
2. **L'ami ensuite :** lui envoyer l'adresse et une seule phrase : « crée une spéciale sur une route que tu aimes, puis roule dessus ».
3. Baptiste observe sans parler ni aider, et note chaque hésitation.
4. Répondre par écrit ci-dessous.

| Question                                                 | Réponse |
| -------------------------------------------------------- | ------- |
| L'ami est-il arrivé au volant sans aide ?                |         |
| Combien de temps, jusqu'au premier tracé valide ?        |         |
| Où a-t-il hésité ou s'est-il trompé ?                    |         |
| A-t-il compris un refus du tracé sans explication ?      |         |
| L'attente de la génération l'a-t-elle découragé ?        |         |
| La route ressemble-t-elle à celle qu'il connaît ?        |         |
| Le score ou les chicanes ont-ils changé son tracé ?      |         |
| A-t-il su faire un aller-retour, si sa route s'y prête ? |         |
| Est-il revenu modifier son tracé de lui-même ?           |         |

## Critère de passage de l'epic

- [ ] Un ami crée et roule une spéciale sans aide, sur son propre PC et sans bug bloquant.
- [ ] Le pilotage reste au niveau de la fin de l'epic 2.

Si la réponse est non : les défauts vont dans une fiche de retours, comme la story 1.11, et **on ne passe pas à l'epic de course.**
