# Story 3.2 : Tracé automatique entre plusieurs points

**Statut : code livré, validation de Baptiste attendue**

## Objectif

Le cœur de l'epic. Cliquer sur la carte pose un point, et la route réelle se trace toute seule entre les points. Le modèle d'interaction est repris de [gpx.studio](https://gpx.studio/fr/help/toolbar/routing).

## Ce qu'on reprend de gpx.studio

| Geste             | Comportement                                                  |
| ----------------- | ------------------------------------------------------------- |
| Clic sur la carte | Pose un point à la fin du tracé et trace le segment           |
| Glisser un point  | Recalcule seulement les deux segments qui le touchent         |
| Survoler le tracé | Fait apparaître un point à glisser pour insérer un passage    |
| Clic sur un point | Menu : supprimer, avec le segment recalculé entre ses voisins |
| Inverser          | Change le sens du tracé                                       |

**Ce qu'on ne reprend pas :**

- Le routage désactivé en ligne droite : ce serait une route inventée. Si BRouter échoue, le tracé reste au dernier état valide, avec un message.
- « Retour au départ » : une boucle fermée fait se toucher le départ et l'arrivée. « Aller-retour » arrive à part, en story 3.7, car il demande un vrai travail sur le jeu.
- Son serveur GraphHopper, qui lui appartient et n'a pas de profil voiture. On garde BRouter, déjà utilisé par les fixtures.

Son code est sous licence MIT, en Svelte : on s'inspire de la logique. **Lire `RoutingControls.ts` et `routing.ts` de son dépôt au début de la story**, et garder sa notice de licence si on en recopie un morceau.

## À faire

- `src/geo/brouter.ts` : appel `https://brouter.de/brouter`, profil `car-fast`, format `geojson`, via `requestText` de `http.ts` avec délai, reprise et annulation. Messages français pour `from-position`, `via1-position` ou `to-position not mapped`, et pour le dépassement de délai.
- Affichage avec les composants de mapcn, sans les modifier : `MapRoute` pour le tracé, `MapMarker` avec `draggable` et `onDragEnd` pour les points.
- `src/editor/` : logique pure, sans React ni MapLibre, testable dans Node.
  - Modèle : une liste de points d'ancrage et un segment par paire de points voisins.
  - Chaque segment garde sa géométrie et ses tags `highway` et `surface`, renvoyés dans `messages` par BRouter.
  - Seuls les segments touchés sont redemandés, jamais tout le tracé.
- Un point se recale sur la route trouvée. **Au-delà de 150 m de l'endroit cliqué, le point est refusé** avec un message : BRouter accroche sans prévenir, jusqu'à 280 m mesurés dans un champ.
- Appel uniquement au relâchement du point, jamais pendant le glissement : la carte montre alors un trait pointillé provisoire.
- Annuler et rétablir, boutons et `Ctrl+Z` / `Ctrl+Y`. Historique en instantanés immuables, sans dépendance nouvelle.
- Tout vider, avec confirmation.
- Panneau latéral : liste des points avec leur rang et leur distance. Chaque point peut y être supprimé au clavier, car un marqueur de carte ne suffit pas pour l'accessibilité.
- Longueur totale affichée en direct.
- Brouillon gardé dans `localStorage`, relu avec une validation : une entrée illisible revient à un brouillon vide.

## Critères d'acceptation

**Vérifié sans toi**

- [x] `editor.check.ts`, sans réseau, à partir de réponses BRouter enregistrées dans `fixtures/` :
  - ajouter, insérer, déplacer et supprimer redemandent uniquement les segments attendus ;
  - les segments assemblés n'ont ni doublon ni trou à leurs jonctions ;
  - annuler puis rétablir redonne exactement le même tracé ;
  - inverser deux fois redonne le tracé de départ.
- [x] Une réponse lente qui arrive après un nouveau déplacement est ignorée : la requête est annulée et ne peut pas écraser le tracé.
- [ ] Sur une panne de BRouter, le tracé valide reste affiché, avec un message clair et la possibilité de réessayer.
- [x] `pnpm lint`, `pnpm build` et `pnpm check:determinism editor` passent.

## Pièges

- Un point posé sur une route voisine crée un aller-retour en cul-de-sac entre deux segments : la story 3.3 le refuse, mais l'affichage doit le rendre visible.
- `Ctrl+Z` pendant qu'une requête est en cours : annuler la requête d'abord.
- Le serveur public de BRouter n'a pas de limite publiée : rester à un appel par geste. Une rafale de 5 requêtes est passée le 02/11/2026, ce n'est pas une garantie.
- Ne pas utiliser l'altitude de BRouter : voir la story 3.5.
