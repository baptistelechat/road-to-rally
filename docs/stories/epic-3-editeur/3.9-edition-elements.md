# Story 3.9 : Édition des éléments

**Statut : fait, à valider dans le navigateur.** Logique dans `src/editor/chicanes.ts`, vérifiée par `editor-elements.check.ts` plutôt que `editor.check.ts`. Le document ne garde que les choix du joueur : les chicanes automatiques restent dans le résultat de l'analyse. Ajout : bouton du panneau, dans le plus grand espace libre, ou clic droit sur le tracé. Limite entre deux chicanes : 80 m, le long du tracé.

## Objectif

Le joueur a le dernier mot : il déplace, supprime ou ajoute chaque chicane. Sur une portion roulée deux fois, une chicane se place une seule fois et se franchit dans les deux sens.

## À faire

- Glisser une chicane le long du tracé, jamais hors de la route.
- Changer son côté de départ, la supprimer depuis un menu, en ajouter une à l'endroit voulu.
- Un élément touché par le joueur est marqué comme le sien et n'est plus jamais recalculé automatiquement.
- Quand le tracé change :
  - les chicanes automatiques sont recalculées ;
  - celles du joueur se recalent sur le tracé à partir de leur position géographique ;
  - si elles n'y sont plus, elles sont retirées, **avec un message qui le dit** ;
  - une chicane supprimée par le joueur ne revient pas sur la portion inchangée.
- Le bouton « Rétablir les chicanes automatiques » remet à zéro, avec confirmation.
- Les éléments passent dans l'historique d'annulation de la story 3.2 et dans le brouillon.
- Liste des chicanes dans le panneau, utilisable au clavier.
- Le plafond d'une par km ne s'applique qu'aux chicanes automatiques : le joueur fait ce qu'il veut, dans la limite de distance entre deux chicanes.

## Pièges

- Dans l'éditeur, garder une position géographique : l'abscisse change dès que le tracé bouge. Elle n'est calculée qu'au moment de « Rouler ».
- Une chicane recalée sur une route qui repasse à proximité peut sauter sur la mauvaise branche : borner la recherche.
- Le lien de partage de l'epic 6 devra porter ces choix : garder un format de données simple.
