# BDR-20261103205616-2 — Pointillés selon les voies OSM, jamais selon la largeur

**Décision** : Une ligne pointillée entre chaque paire de voies voisines (aucune sur une voie, une sur deux, deux sur trois). Le nombre de voies vient de `lanesFromTags` : `lanes` s'il est lisible, sinon 1 pour un sens unique ou un giratoire, 2 ailleurs ; `lanes=1` sur une grande route à double sens compte 2. Il passe par `StageData.lanes` jusqu'au rendu ; une spéciale sans cette donnée garde 2 voies partout.

**Pourquoi** : Correction de Baptiste : une première version déduisait les voies de la largeur (÷ 3 m) et retirait la ligne des petites routes à double sens de 5 m.

**Alternatives considérées** : Nombre de voies tiré de la largeur.
