# BDR-261122_0721-2 — Horloge permise pour le rythme réseau de src/geo

**Décision** : Le contrôle de portabilité de `geo.check.ts` (`checkPortability`) parcourt `src/geo` sous-dossiers compris, ignore les commentaires et autorise `Date.now` uniquement dans les fichiers de la liste `NETWORK_PACING` : `ignRoads.ts` et `decor/fetchDecor.ts`. `DOMParser`, `fs`, `window` et `Math.random` restent interdits partout.

**Pourquoi** : Dans ces deux fichiers, l'horloge règle seulement l'espacement des requêtes WFS (une par seconde pour l'IGN) et l'abandon du décor après `DECOR_TIME_BUDGET` (2 min). Elle décide quand télécharger, jamais ce que devient la spéciale une fois les données reçues : la cuisson reste déterministe.

**Alternatives considérées** : Injecter une horloge dans les options HTTP pour garder l'interdiction totale, plus lourd pour un gain nul sur la cuisson.
