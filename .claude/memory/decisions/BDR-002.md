# BDR-002 — Rapier déterministe en direct, simulation sans rendu

**Décision** : Utiliser `@dimforge/rapier3d-deterministic-compat` directement, sans `@react-three/rapier`, avec une simulation TypeScript pure dans `src/sim/`, capable de tourner dans Node.

**Pourquoi** : Le fantôme, le replay et le futur rejeu serveur des chronos reposent sur un pas fixe et le rejeu des entrées.

**Alternatives considérées** : `@react-three/rapier`, plus simple à brancher mais incompatible avec cet objectif.
