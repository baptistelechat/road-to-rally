# BDR-261104_1546-2 — Score de l'éditeur en entier dans le bandeau, sans verdict

**Décision** : la fenêtre « Score détaillé » (`ScorePanel.tsx`) est supprimée. Épingles et ligne droite max, avec le surlignage carte au survol ou au focus, rejoignent le bandeau `StatsStrip.tsx` au-dessus de la courbe. Le verdict « roulante / sinueuse / très sinueuse » n'est plus affiché ; `computeTraceStats` le calcule toujours pour les checks `trace-stats`.

**Pourquoi** : demande de Baptiste, la fenêtre répétait le bandeau. Le verdict n'est qu'une étiquette des virages par km (< 2, < 5, au-delà), déjà affichés à côté.

**Alternatives considérées** : garder le verdict comme lecture rapide pour un néophyte.
