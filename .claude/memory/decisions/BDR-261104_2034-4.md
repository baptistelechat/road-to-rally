# BDR-261104_2034-4 — Arrivée annoncée : « Arrivée », icône A3b

**Décision** : Une note posée sur la ligne d'arrivée, annoncée comme un virage, sur les spéciales seulement (le circuit d'essai boucle). La voix dit simplement « Arrivée ». Icône A3b : l'arche à damier vue du pilote remplit toute la pilule, bord blanc.

**Pourquoi** : Kokoro reste plat sur « Arrivée, à fond ! » et ses variantes : une annonce sobre vaut mieux qu'un enthousiasme forcé. L'arche panoramique se distingue de toutes les autres notes.

**Alternatives considérées** : Drapeau à damier, pilule à damier, arche dans la pastille, arche gonflable rouge, arche + drapeau. Phrases « Arrivée, plein gaz ! », « Allez, allez, arrivée ! », etc.
