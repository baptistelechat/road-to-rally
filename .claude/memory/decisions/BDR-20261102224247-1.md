# BDR-20261102224247-1 — Voix du copilote générée avec Kokoro

**Décision** : Les mots du copilote sont générés une fois pour toutes avec Kokoro v1.0 (voix `ff_siwis`), et livrés en WAV PCM mono dans `public/audio/copilot/`. Le script `scripts/generate-copilot-words.py` reste dans le dépôt pour ajouter des mots, le modèle de 115 Mo se retélécharge. L'écoute par Baptiste reste à faire.

**Pourquoi** : Ses phrases courtes sont transcrites presque mot pour mot. Les poids sont sous Apache 2.0 et les données de la voix sous CC BY, à créditer dans `CREDITS.md`. Le WAV évite le silence d'encodage du MP3, et ffmpeg n'est pas installé.

**Alternatives considérées** : Piper `fr_FR-mls-medium`, à licence claire, mais ses annonces courtes restaient incomprises pour les 5 locuteurs essayés en phrase courte. Les autres voix françaises de Piper, écartées pour leur licence (non commerciale ou AGPL). La voix Windows, à la licence de distribution pas claire, gardée seulement comme témoin de test. Enregistrer les mots soi-même reste possible sans toucher au code.
