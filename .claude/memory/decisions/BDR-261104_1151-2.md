# BDR-261104_1151-2 — Choix visuels des options en cartes avec aperçu

**Décision** : Les styles de mini-carte et de compteur se choisissent sur `MenuCards` : une rangée de grandes cartes sous le titre, avec aperçu, en `radiogroup`, parcourue à la manette comme les autres boutons. La mini-carte a une carte « Aucune » qui remplace l'interrupteur Activée / Désactivée ; le stockage garde `miniMapEnabled` + `miniMapStyle`. L'aperçu du compteur est le vrai composant réduit, celui de la mini-carte un schéma (`MiniMapPreview`), la vraie carte demandant une spéciale chargée. Le panneau d'options passe à 34rem et défile s'il est trop haut. Les compteurs de performance (`Stats` de drei) sont empilés en colonne sous la mini-carte.

**Pourquoi** : Baptiste veut voir tous les choix d'emblée en grand plutôt que dans une liste à ouvrir.

**Alternatives considérées** : Vignettes à gauche des noms dans le menu déroulant `MenuSelect` (essayées puis refusées).
