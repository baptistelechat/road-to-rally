# BDR-20261101115222-3 — Les tracés qui se croisent sont refusés en v0

**Décision** : Le pipeline refuse un tracé qui se croise ou dont deux chaussées se touchent, en indiquant l'endroit. L'éditeur de l'epic 3 empêchera ensuite de les dessiner.

**Pourquoi** : `nearest` cherche à plat et suppose une seule route à chaque position : un croisement ferait sauter l'abscisse d'une branche à l'autre. Ponts et carrefours coûteraient cher pour un cas rare.

**Alternatives considérées** : La prise en charge complète, prévue dans la première liste de l'epic 2.
