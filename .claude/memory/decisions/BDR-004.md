# BDR-004 — Suspension par raycast Rapier, forces de pneus maison

**Décision** : Le contrôleur de véhicule de Rapier gère la suspension par raycast. Son adhérence est mise à zéro (`setWheelFrictionSlip`, `setWheelSideFrictionStiffness`), et `src/sim/vehicle.ts` applique ses propres forces de pneus.

**Pourquoi** : Le pilotage prime sur tout dans ce projet : le code doit décider du grip, de la glisse et des assistances, réglés dans `src/sim/carConfig.ts`.

**Alternatives considérées** : Non retrouvées, la décision date d'avant le résumé de session.
