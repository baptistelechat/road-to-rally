# BDR-20261101191443-4 — Menu de départ et de pause, simulation gelée hors course

**Décision** : un état `screen` (`start`, `race`, `pause`) dans `hudStore.ts` gèle la simulation hors course, et le sélecteur de carte vit dans `GameMenu.tsx`. Échap et Start ouvrent ou ferment la pause, A et Start valident, et le son se coupe en pause. Au départ, la manette est refusée tant que le son est bloqué. L'interface n'affiche aucun texte d'aide : elle doit se comprendre seule. Mise à jour : en pause, A active la ligne sélectionnée au lieu de reprendre directement, et Start reprend toujours (voir [BDR-20261101201935-2](BDR-20261101201935-2.md)).

**Pourquoi** : le premier clic devient un geste de jeu plutôt qu'une contrainte, et le chrono ne tourne pas dans le vide. Le jeu se joue surtout à la manette : une seule action souris au lancement, puis Start donne accès à tout le menu.

**Alternatives considérées** : message d'avertissement dans le HUD (assimilé à un message de debug), PWA (ne règle pas le blocage), Electron (téléchargement et packaging, à revoir si Steam devient un objectif).
