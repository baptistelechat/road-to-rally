# BDR-261123_2208-1 — Import GPX dans l'éditeur seul, en tracé modifiable

**Décision** : le bouton « Importer un GPX » vit uniquement sur la page « Mes spéciales » de l'éditeur (`ImportGpxButton.tsx`). Il a été retiré du menu de départ et du road-book de pause, avec le chargement sur place (`imported` dans `Game.tsx` et `useGameSession.ts`). À l'import, le GPX est converti en tracé d'éditeur par `src/editor/fromGpx.ts` : un point d'ancrage par kilomètre, les points du GPX gardés tels quels entre deux ancrages, `ways` vide. La vignette dessine l'axe de la route (`outline` de `StoredStage`) quand il n'y a pas de tracé.

**Pourquoi** : cohérence demandée par Baptiste (un seul endroit pour créer une spéciale) et envie de pouvoir rééditer une spéciale importée plus tard. Garder les points du GPX évite que BRouter redessine la route tant qu'on ne déplace pas un ancrage.

**Note (2026-11-24)** : les spéciales importées depuis le jeu avant ce changement n'ont pas gardé de tracé : ni « Modifier » ni 🔄 « Régénérer » (pastille jaune sans bouton). Il faut les supprimer et les réimporter depuis l'éditeur.

**Alternatives considérées** : import en jeu non modifiable (refusé) ; recalcul complet du GPX par BRouter entre ancrages (aurait changé la route importée).
