# BDR-261104_1032-1 — Éditeur en un seul mode, sans bascule Éditer/Déplacer

**Décision** : La carte de l'éditeur n'a plus de mode : un clic pose un point, les points et les chicanes se glissent toujours, un clic sur un élément ouvre son menu. Garde-fous dans `MapClickHandler.tsx` : `clickTolerance` à 8 px (MapLibre : 3), aucun point à moins de 22 px du centre d'un marqueur, ni sur la bande d'une chicane, ni si un menu était ouvert à l'appui. La poignée d'insertion (`InsertHandle.tsx`) se cache sur la bande d'une chicane. `ModeSwitch.tsx` et `mapMode` sont supprimés.

**Pourquoi** : Baptiste trouvait la bascule peu intuitive. Les deux modes cachaient deux défauts de clic : déplacer la carte posait un point (tolérance de 3 px), et rater un point de quelques pixels en créait un autre. Corriger ces défauts rend la bascule inutile.

**Alternatives considérées** : Garder les deux modes. Raccourci clavier pour basculer. Clic long pour poser un point.
