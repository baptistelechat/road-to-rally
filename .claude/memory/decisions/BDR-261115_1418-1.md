# BDR-261115_1418-1 — Icônes de commandes : pack Kenney, table unique, sync

**Décision** : Les icônes viennent du pack Kenney Input Prompts, dossiers SVG seulement, rangés dans `assets-src/kenney-input/<Appareil>/` (commité, jamais servi, sans le niveau `Vector`). `src/input/inputPrompts.ts` est la source unique : action → groupes d'icônes par appareil (`keyboard`, `xbox`, `playstation`), avec des variantes AZERTY/QWERTY pour le clavier. `pnpm icons:sync` (`scripts/sync-input-icons.ts`) copie dans `public/input/<appareil>/` seulement les icônes listées et supprime les orphelines. Un nom inconnu échoue avec les noms proches. `--check` tourne en tête de `pnpm build`. Le reste du pack (PNG, polices, aperçus, zip) est parti à la Corbeille.

**Pourquoi** : on garde tout le pack pour un futur appareil sans servir 1 500 fichiers. Une faute de frappe dans la table casse le build au lieu d'afficher une icône manquante en production.

**Alternatives considérées** : police Kenney (monochrome, perd les couleurs des boutons), PNG Default/Double (flous ou lourds), tout le pack dans `public/` (19 Mo déployés), zip seul (copie manuelle à chaque ajout).
