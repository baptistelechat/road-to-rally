# BDR-261122_0500-4 — Routes ou physique changées : records et fantômes à zéro

**Décision** : Quand les routes, les obstacles ou la physique changent, on n'essaie pas de garder les anciens chronos : on incrémente le format. `StageRecord.version` passe à 2 (`src/game/stageRecords.ts`, écrit dans `useGameLoop.ts`) et l'ancien meilleur temps seul (`bestLapKey`) n'est plus repris ; `GhostData.version` passe à 3 (`src/sim/ghostTrack.ts`). Tout ce qui est plus ancien est ignoré.

**Pourquoi** : Baptiste : « on va supprimer tous les vieux fantômes, on est en dev », puis « on supprime les anciens chronos, ce n'est plus les mêmes routes et les mêmes obstacles, alors on ne peut pas comparer ». Les cartes livrées gardent un `recordId` fixe (`road`, `mountain`) : sans changement de format, un vieux record survivrait à une route refaite.

**Alternatives considérées** : Rendre les fantômes compatibles avec la nouvelle physique, clé de record par empreinte de spéciale pour les cartes livrées.
