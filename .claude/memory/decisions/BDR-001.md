# BDR-001 — Next.js 16 dès le socle plutôt que Vite

**Décision** : L'app démarre sur Next.js 16 (App Router), avec le jeu dans un Client Component chargé via `next/dynamic` et `ssr: false`.

**Pourquoi** : Baptiste juge qu'un transfert de framework plus tard serait très lourd. L'éditeur, le partage et le futur backend vivront dans la même app.

**Alternatives considérées** : Vite + React, prévu en alternative par le PRD car la v0 n'a pas de backend. Écarté malgré le SSR inutile pour le jeu lui-même.
