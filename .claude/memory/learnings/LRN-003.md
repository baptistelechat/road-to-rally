# LRN-003 — Lag : comparer dev et production, une variable par test

**Pattern observé** : Un lag mesuré en mode dev peut ne pas exister en production. Comparer les deux doit venir avant toute recherche de cause dans le code.

**Contexte** : Plusieurs captures et allègements du jeu n'ont pas établi la cause de [BLK-002](../blockers/BLK-002.md). Le test en production l'a isolée. Ce test changeait aussi le réseau : il a fallu un test de plus pour séparer les deux.

**Application future** : Sur un problème de performance, tester d'abord le build de production, sur la machine et avec le périphérique concernés. Ne changer qu'une variable par test.
