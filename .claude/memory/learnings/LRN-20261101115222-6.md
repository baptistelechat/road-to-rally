# LRN-20261101115222-6 — Le filtre rtk peut faire croire à un diff vide

**Pattern observé** : `git diff` passé dans un `grep` n'a renvoyé que `--- Changes ---`, car RTK réécrit la sortie avant le `grep`. `rtk proxy git --no-pager diff` donne le vrai contenu.

**Contexte** : Rédaction d'un message de commit le 2026-11-01, avec 19 fichiers stagged.

**Application future** : Ne jamais conclure à une absence de changement, ni rédiger un message de commit, à partir d'une sortie filtrée puis repassée dans un `grep`.
