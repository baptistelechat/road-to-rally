# LRN-20261101191443-1 — Une manette ne débloque pas l'audio du navigateur

**Pattern observé** : une pression sur une manette n'est pas un geste valide pour le navigateur. La spec HTML n'accepte que `keydown` (hors Échap), `mousedown`, `pointerdown` (souris), `pointerup` (hors souris) et `touchend` : l'`AudioContext` reste suspendu tant que le joueur n'a utilisé que sa manette.

**Contexte** : jeu pensé pour la manette. Le son ne démarrait qu'au clic, et les entrées manette n'y changeaient rien.

**Application future** : prévoir un geste souris ou clavier au lancement, là où le joueur a encore la souris en main, puis laisser la manette prendre le relais. Voir aussi GLRN-221 et GLRN-222.
