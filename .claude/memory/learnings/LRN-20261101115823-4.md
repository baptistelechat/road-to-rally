# LRN-20261101115823-4 — R3F : bouger la caméra avant la mise à jour d'OrbitControls

**Pattern observé** : drei met à jour `OrbitControls` en `useFrame` priorité -1. Une caméra déplacée à la priorité par défaut s'affiche donc une image sans les limites appliquées. En priorité -2, elles s'appliquent dans la même image. Déduit du code de drei, le scintillement n'a pas été mesuré.

**Contexte** : Pilotage de la caméra du garage à la manette, dans `GaragePadControls.tsx`.

**Application future** : Piloter la caméra en amont d'`OrbitControls` et le laisser gérer les limites, sans les recoder.
