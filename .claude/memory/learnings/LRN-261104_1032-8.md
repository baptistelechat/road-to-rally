# LRN-261104_1032-8 — MapLibre : l'id d'une source doit suivre la clé React

**Pattern observé** : Avec `MapRoute` (mapcn), un id de source tiré de l'index (`island-${i}`) alors que la clé React vient de la position : un élément inséré en tête fait changer d'id un composant gardé par React, qui recrée une source encore tenue par un autre, d'où « Source "route-source-island-3" already exists ».

**Contexte** : Erreur à l'ajout d'un point qui créait un rond-point avant les autres.

**Application future** : Dans une liste de calques MapLibre, construire l'id de source à partir de la même valeur stable que la clé React, jamais de l'index.
