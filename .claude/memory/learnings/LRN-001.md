# LRN-001 — @react-three/rapier fige une version non déterministe

**Pattern observé** : `@react-three/rapier` 2.2.0 dépend en dur de `@dimforge/rapier3d-compat` 0.19.2, alors que le paquet `@dimforge/rapier3d-deterministic-compat` existe en 0.21.0. Passer par le wrapper exclut donc la variante déterministe.

**Contexte** : Choix de la physique pour le fantôme et le rejeu des entrées, vérifié avec `npm view` le 31/10/2026.

**Application future** : Vérifier les dépendances d'un wrapper avec `npm view <paquet> dependencies` avant de l'adopter quand une garantie dépend de la variante du moteur.
