# LRN-261124_2125-5 — Mesurer une génération hors navigateur, pas sur captures

**Pattern observé** : trois hypothèses sur captures (largeur du tube, relief dans le tube, roche manquante) n'ont rien donné. `scripts/debug-tunnels.ts` (`pnpm tsx scripts/debug-tunnels.ts <gpx> <cache.json>`) génère la spéciale dans Node et mesure, par tunnel, la longueur, la demi-largeur, le bord local min/max, les triangles de roche et les sommets de terrain dans le tube. Il a montré en une passe la route qui rétrécit (4,25 contre 5,5 m), les tunnels sans roche et le faux tunnel de 6 m. Le cache JSON évite de redemander l'IGN.

**Contexte** : B-15, deux GPX de T-6.

**Application future** : pour tout défaut de génération géo, écrire un petit script de mesure sur `buildStage` avec les entrées en cache avant de corriger. Ce n'est pas un check : il se lance sans l'autorisation exigée pour `check:determinism`.
