# LRN-20261101115823-6 — Panneau navigateur : serveur déjà lancé et erreurs périmées

**Pattern observé** : Deux pièges vus ensemble. `preview_start {name}` annonce un autre port alors que `next dev` s'arrête aussitôt si un serveur tourne déjà : `navigate` échoue ensuite, et `preview_start {url}` sur le serveur existant fonctionne. Le journal de la console survit aux rechargements : après des modifications à chaud, il peut garder des erreurs périmées.

**Contexte** : Serveur de Baptiste déjà actif sur le port 3000 ; 38 erreurs `flaps is not defined` restées dans le journal après le retrait du pendule, alors que le code était correct.

**Application future** : Relire `preview_logs` en cas d'échec de navigation. Juger une erreur à l'évolution du compteur après rechargement, pas à sa simple présence.
