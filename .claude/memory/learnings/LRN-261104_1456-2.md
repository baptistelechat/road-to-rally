# LRN-261104_1456-2 — mapcn : l'effet voit encore l'ancien style au changement de fond

**Pattern observé** : quand le prop `styles` de mapcn change, un `useEffect` qui dépend du fond se déclenche alors que `isLoaded` est encore vrai pour l'ancien style. `setLayoutProperty` / `setPaintProperty` sur un calque du nouveau style lève « Cannot style non-existing layer ».

**Contexte** : bouton « Routes » qui masque les calques routes du fond satellite (`BasemapTuning.tsx`), erreur en passant de Clair à Satellite.

**Application future** : garder `map.getLayer(id)` avant d'agir et laisser `isLoaded` dans les dépendances. mapcn recharge le style avec `setStyle(..., { diff: false })`, `isLoaded` repasse à faux puis à vrai au `style.load`, et l'effet s'applique alors sur le bon style.
