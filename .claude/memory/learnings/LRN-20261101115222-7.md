# LRN-20261101115222-7 — Le formateur casse les Edit parallèles sur un tableau

**Pattern observé** : Le hook de formatage réaligne un tableau Markdown dès la première modification. Dans un lot d'`Edit` parallèles sur le même tableau, les suivants échouent car leur texte d'origine n'existe plus.

**Contexte** : Renommage des valeurs `?map=` dans la story 2.3 le 2026-11-01. Voir aussi GLRN-103.

**Application future** : Remplacer toutes les lignes d'un tableau en un seul `Edit`, et relire le fichier après un échec.
