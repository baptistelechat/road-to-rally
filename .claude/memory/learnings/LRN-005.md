# LRN-005 — Sur AZERTY, la touche M a le code Semicolon

**Pattern observé** : `KeyboardEvent.code` suit la position physique de la touche, pas la lettre affichée. Sur AZERTY, le M porte le code `Semicolon`, pas `KeyM`.

**Contexte** : La touche de coupure du son ne répondait pas au clavier de Baptiste.

**Application future** : Lier une action à une lettre avec `event.key`, ou déclarer les deux codes. Garder `code` pour les touches choisies par leur position, comme ZQSD et WASD.
