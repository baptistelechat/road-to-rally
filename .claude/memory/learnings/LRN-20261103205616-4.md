# LRN-20261103205616-4 — Brouillon éditeur : nouveau tag BRouter après recalcul seulement

**Pattern observé** : Le brouillon de l'éditeur (`localStorage`) garde les segments BRouter avec leurs tags déjà parsés. Un tag ajouté au parseur (ici `junction`) n'existe pas dans les segments déjà tracés : rien n'apparaît tant qu'un point voisin n'est pas déplacé, ce qui recalcule les segments qui le touchent.

**Contexte** : Les ronds-points ne s'affichaient pas sur un tracé existant alors que la détection marchait sur une route neuve.

**Application future** : Après tout ajout de donnée tirée de BRouter, prévenir Baptiste qu'il faut déplacer un point, ou tester sur un segment recalculé, avant de chercher un bug. Ne jamais recalculer les segments en silence au chargement : le tracé pourrait changer.
