# LRN-261115_1418-5 — Vercel clone tout le repo au build, ne sert que le rendu

**Pattern observé** : Vercel clone tout le repo sur la machine de build, puis ne met en ligne que le résultat de `next build` et le contenu de `public/`. Un dossier hors `public/` (ici `assets-src/`) est présent au build mais n'a aucune URL. `.vercelignore` le retirerait aussi du build.

**Contexte** : Choisir où garder le pack Kenney complet sans le déployer, tout en laissant `icons:sync --check` le lire pendant `pnpm build`.

**Application future** : Sources d'assets lues par un script de build → hors `public/`, sans `.vercelignore`. Fichiers à servir → `public/` seulement.
