# LRN-20261101233659-5 — Un cycle irrégulier dans PeriodicWave évite un AudioWorklet

**Pattern observé** : Un moteur peut se synthétiser avec des nœuds natifs : calculer un cycle complet (deux tours), avec une impulsion amortie par cylindre, légèrement différente pour chacun, en prendre les coefficients de Fourier pour `createPeriodicWave`, puis jouer l'oscillateur à `rpm / 120` Hz.

**Contexte** : Les écarts entre cylindres font apparaître des harmoniques sous le rythme des explosions, nulles dans une onde régulière. Ils servent ici à obtenir le grondement du 5 cylindres. Deux variantes légèrement désaccordées et une instabilité lente sur `detune` évitent la répétition parfaite.

**Application future** : Essayer cette voie avant un `AudioWorklet`. Il faut assez d'harmoniques : 256 pour monter à environ 1 900 Hz à 900 tr/min. Le calcul se fait à la création de la voix (coût non mesuré). L'onde reste strictement périodique, donc l'instabilité reste nécessaire. Le rendu reste à juger à l'oreille.
