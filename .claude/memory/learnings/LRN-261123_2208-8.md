# LRN-261123_2208-8 — WFS BD TOPO : position au sol en texte, BBOX CQL lat,lon

**Pattern observé** : sur `https://data.geopf.fr/wfs/ows`, couche `BDTOPO_V3:troncon_de_route`, l'attribut `position_par_rapport_au_sol` est un **texte** : `CQL_FILTER=position_par_rapport_au_sol<0` renvoie 0 résultat, `IN ('-1','-2','-3')` renvoie les tunnels. Dans le `CQL_FILTER` avec `SRSNAME=EPSG:4326`, `BBOX(geometrie, lat_min, lon_min, lat_max, lon_max)` a fonctionné dans l'ordre **lat,lon**. `cpx_numero` donne le numéro de route (ex. `'D531'`).

**Contexte** : recherche de tunnels réels (gorges de la Bourne, Grands Goulets) pour le test T-6, puis génération de GPX via BRouter (`https://brouter.de/brouter?lonlats=lon,lat|lon,lat&profile=car-fast&format=gpx`).

**Application future** : pour trouver un ouvrage réel à tester (tunnel, pont), interroger le WFS avec ces filtres, puis demander un GPX à BRouter entre deux points de la route qui l'encadrent, et vérifier l'écart de la trace à l'ouvrage. Voir aussi GLRN-261115_2236-2 (paramètre BBOX hors CQL).
