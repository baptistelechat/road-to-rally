# LRN-261115_1418-4 — Pack Kenney Input Prompts : choisir le dossier Vector

**Pattern observé** : Chaque appareil du pack a 4 formats : `Default` (PNG 64 px), `Double` (PNG 128 px), `Fonts` (police à glyphes `U+E000…`) et `Vector` (SVG). Seul `Vector` garde les variantes colorées (`xbox_button_color_a` en vert `#7DB700`, `playstation_button_color_cross` en violet `#7C66E8`) en restant net à toutes les tailles. La police est monochrome. Les noms suivent une convention stable entre appareils (`xbox_rt` ↔ `playstation_trigger_r2`, `xbox_button_menu` ↔ `playstation5_button_options`). Les SVG simples ont `fill="#FFFFFF"`, adaptés à un thème sombre.

**Contexte** : Remplacement des aides texte par des icônes, sans perdre les vraies couleurs des boutons.

**Application future** : Ajouter un appareil en lisant les noms dans `assets-src/kenney-input/<Appareil>/`, en préférant les variantes `_color_`. Le pack complet est téléchargeable sur kenney.nl (CC0).
