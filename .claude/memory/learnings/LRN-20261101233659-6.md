# LRN-20261101233659-6 — Mesurer un son Web Audio sans l'entendre

**Pattern observé** : Depuis le navigateur, patcher `AudioNode.prototype.connect` pour brancher un `AnalyserNode` sur tout nœud relié à `AudioDestinationNode` permet de lire crête, niveau et valeurs invalides, sans modifier le code du jeu.

**Contexte** : Un agent ne peut pas écouter le rendu. Trois pièges rencontrés : le patch doit être posé avant le branchement du contexte (naviguer avec `window.next.router.push` le conserve) ; en Strict Mode, garder le premier contexte vu laisse la sonde sur un contexte fermé, il faut garder le dernier ; et un contexte déjà branché lui échappe. Un clic réel a été utilisé pour débloquer le son.

**Application future** : Vérifier ainsi l'absence de silence, d'écrêtage et de `NaN`. Cela ne remplace pas l'oreille : le réalisme reste à faire juger par Baptiste.
