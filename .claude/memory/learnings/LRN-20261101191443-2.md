# LRN-20261101191443-2 — Installer en PWA ne lève pas le blocage de l'audio

**Pattern observé** : la doc Chrome, datée de 2017, dit que le son est permis sans geste pour une PWA installée sur ordinateur. Sur Pawzzle, qui est une PWA, Baptiste constate pourtant le même blocage.

**Contexte** : la PWA avait été recommandée à partir de cette doc seule, sans test, pour jouer à la manette sans clic. Le retour de Baptiste l'a écartée. C'est un constat de terrain, sans test dédié du cas PWA sur ordinateur.

**Application future** : ne pas proposer la PWA comme solution au blocage de l'audio.
