# LRN-20261101115222-5 — Plusieurs itinéraires : BRouter et OSRM diffèrent

**Pattern observé** : `alternatives=true` sur le serveur public d'OSRM n'a renvoyé qu'un itinéraire sur les deux trajets testés. Avec `alternativeidx` de 0 à 3, BRouter en a donné 4 distincts vers Grenoble, et un seul à Turini. `MapRoute` de mapcn affiche les itinéraires sans les calculer : son exemple appelle OSRM, mais BRouter peut l'alimenter.

**Contexte** : Comparaison du 2026-11-01 pour l'éditeur de l'epic 3, sur deux trajets seulement. BRouter a aussi répondu « no track found » sur un autre trajet testé.

**Application future** : Pour proposer des variantes, tester BRouter d'abord et comparer les géométries : quatre index ne garantissent pas quatre routes différentes.
