# LRN-20261102121514-5 — ENAMETOOLONG : commande Bash trop longue sous Windows

**Pattern observé** : Sous Windows, l'outil Bash refuse une commande trop longue avec `ENAMETOOLONG` et n'exécute rien du tout, même les premières lignes.

**Contexte** : Un seul appel enchaînait plusieurs correctifs Python et la création de fichiers par heredoc.

**Application future** : Pour un gros correctif, écrire d'abord le script dans le scratchpad avec `Write`, puis l'exécuter avec une commande courte.
