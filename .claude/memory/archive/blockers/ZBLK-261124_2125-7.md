# BLK-261124_2125-7 — « Spéciale plus disponible » après import avec tunnel

**Friction** : après l'import d'un GPX avec tunnel, le jeu affichait « Cette spéciale n'est plus disponible dans ce navigateur ».

**Cause réelle** : la spéciale était bien générée et rangée, mais `validEntry` passait `tunnels[].roof` (tableaux typés) à `parseStage`, qui les refusait.

**Solution** : `validEntry` retire la roche avant `parseStage`, vérifie ses tableaux typés, puis la remet.
