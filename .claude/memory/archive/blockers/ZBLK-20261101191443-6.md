# BLK-20261101191443-6 — Boutons A et Start du menu non testés à la manette

**Friction** : les boutons A et Start du menu n'avaient pas de retour d'essai avec une vraie manette.

**Cause réelle** : aucune anomalie constatée, ce test n'avait simplement pas eu lieu.

**Solution** : Baptiste a validé le son, la pause, Échap, ainsi que A et Start à la manette.
