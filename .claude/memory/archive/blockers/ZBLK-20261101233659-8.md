# BLK-20261101233659-8 — preview_start échoue si next dev tourne déjà

**Friction** : `preview_start` annonce le port 3001, puis la navigation échoue : le serveur s'est arrêté.

**Cause réelle** : Next.js 16 refuse un second `next dev` pour le même dossier, et Baptiste en avait déjà un sur le port 3000. Les journaux du serveur l'indiquent.

**Solution** : Ouvrir directement `http://localhost:3000` avec `navigate`, sans arrêter son serveur.
