# BLK-20261101202404-3 — Tests navigateur qui font planter le PC de Baptiste

**Friction** : Le PC de Baptiste a planté pendant une série de tests Playwright sur le jeu, et il a dû tout couper.

**Cause réelle** : Chromium en fenêtre visible avec le rendu 3D, lancé en même temps que `tsc` et le lint, sur un serveur `next dev` déjà actif.

**Solution** : Une seule commande lourde à la fois, jamais pendant que Baptiste joue ou teste. Pour les tests longs ou gourmands, lui donner la liste à faire lui-même : il a validé ainsi les critères restants des stories 2.7 à 2.9.
