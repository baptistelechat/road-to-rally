# BLK-20261103202354-5 — Modèles Kokoro absents : « long » non régénéré

**Friction** : Le mot « longue » doit devenir « long », mais `.venv-voice/`, `kokoro-v1.0.int8.onnx` et `voices-v1.0.bin` ne sont plus sur la machine, et `kokoro_onnx` n'est pas installé. Les libellés écrits disent « long », la voix dit encore `longue.wav`.

**Cause réelle** : Les fichiers de génération sont ignorés par git et n'ont pas été conservés. Baptiste a demandé de ne rien installer : il n'est pas convaincu par la voix et veut une session dédiée.

**Solution** : À reprendre dans la session voix : choisir la voix, puis réinstaller selon `public/audio/copilot/CREDITS.md` avec son accord, et renommer le mot dans `PACE_WORDS`, le script de génération et `copilot-voice.check.ts`.
