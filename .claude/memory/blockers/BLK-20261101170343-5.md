# BLK-20261101170343-5 — Fond noir des plaques non reproduit, correctif à confirmer

**Friction** : Baptiste a signalé un fond noir derrière les plaques de rallye du garage. Il n'apparaît pas sur les captures du panneau navigateur.

**Cause réelle** : Non confirmée. Les pistes sont l'ombre dessinée dans le canvas, le noir des pixels vides au filtrage, ou une ancienne texture gardée par le rechargement à chaud.

**Solution** : Ombre du canvas retirée et alpha prémultiplié activé. Reste à faire confirmer le résultat par Baptiste après un rechargement complet.
