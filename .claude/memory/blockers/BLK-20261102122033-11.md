# BLK-20261102122033-11 — Worker MapLibre chargé depuis unpkg par mapcn

**Friction** : La revue de sécurité signale `setWorkerUrl` vers `unpkg.com` dans `map.tsx` (gravité moyenne) : du code tiers tourne sur la page de l'éditeur, qui dépend aussi de la disponibilité d'unpkg.

**Cause réelle** : Comportement par défaut de mapcn. Version fixée, et le site n'a ni compte ni paiement.

**Solution** : À faire avant une vraie mise en ligne : servir le fichier depuis notre site, comme le prévoit la doc de mapcn. Cela modifie une ligne de `map.tsx`, donc l'exception à [BDR-20261102122033-3](../decisions/BDR-20261102122033-3.md) reste à valider par Baptiste.
