# BLK-002 — Lag à 5 min en mode dev avec manette Bluetooth

**Friction** : Vers 5 minutes de jeu, le son saccade, puis les entrées prennent un énorme retard. L'image reste à 60 FPS. Reproductible sur le PC de test, sur secteur.

**Cause réelle** : Inconnue dans son mécanisme. Le lag complet n'apparaît qu'avec le mode dev et le Bluetooth réunis. Une session de 6 min en production, Bluetooth et réseau branché, n'a compté qu'un trou de son, contre 1 119 en mode dev. Au clavier en mode dev, le son tient, mais Baptiste sent encore un léger lag, non expliqué. Écartés par les captures : le réseau, la chauffe (calcul de référence stable), la vibration seule, l'accumulation d'ordres audio, une fuite dans le jeu.

**Solution** : Contournement, pas de correctif. En mode dev, manette en filaire (constat de Baptiste, sans capture mesurée). En Bluetooth, production sur `:3001`. Une seule session propre en production avec le réseau : si le lag y revient, capturer avec `F9`.
