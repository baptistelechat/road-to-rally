# BLK-261128_1831-7 — Chrome sur l'Intel malgré le réglage Windows

**Friction** : jeu à 30 FPS ; le diagnostic F9 (qui note maintenant le GPU) montrait Intel UHD 630 sur un portable qui a une GTX 1050, même après le passage de Chrome en « Performances élevées ».

**Cause réelle** : le réglage Windows visait `chrome.exe` dans `AppData\Local\Google\Chrome\Application`, alors que le Chrome lancé était celui de `Program Files\Google\Chrome\Application` (ligne « Command Line » de `chrome://gpu`). `powerPreference: 'high-performance'`, déjà demandé par R3F, ne suffit pas.

**Solution** : réglage sur le bon exécutable, Chrome fermé entièrement puis relancé ; `GL_RENDERER` cite alors la GTX 1050, 60 FPS.
