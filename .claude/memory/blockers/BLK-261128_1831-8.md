# BLK-261128_1831-8 — Palier « ombre du décor » sans effet via les calques

**Friction** : dans Edge (Intel), le mode Auto descendait directement à une résolution floue ; le palier censé couper l'ombre du décor ne gagnait rien.

**Cause réelle** : le décor était rangé sur un calque retiré de `shadow.camera.layers`, mais `WebGLShadowMap.renderObject` teste `object.layers` contre la caméra **principale**. Le décor projetait donc toujours son ombre.

**Solution** : couper `castShadow` sur les objets `userData.shadow` dans un `useFrame` de priorité 1, après les tranches de décor qui le rallument à chaque image, et le rendre à tout le décor au retour.
