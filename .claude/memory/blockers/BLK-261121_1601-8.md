# BLK-261121_1601-8 — Calcul de l'eau : 58 s sur 75 s de génération

**Friction** : Sur la spéciale de Clisson (1,4 km, 265 nappes d'eau BD TOPO), `buildStage` prend 75 s dans Node, dont 58 s pour `planWater` et 14 s pour le terrain. Le profil CPU désigne `landcoverGeometry.ts` (tests d'appartenance aux polygones), `spatialGrid.ts` et `waterSurfaces.ts`. Un premier essai à 230 s venait d'un PC chargé ; avec ou sans ponts, le temps est le même.

**Cause réelle** : Non analysée : probablement des tests point-dans-polygone sur de nombreux polygones larges, sans index spatial suffisant.

**Solution** : À faire dans une session dédiée : profiler `planWater` sur Clisson (entrées en cache possibles avec un script temporaire), indexer les polygones par case, mesurer avant et après.
