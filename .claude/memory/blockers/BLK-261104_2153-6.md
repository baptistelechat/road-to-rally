# BLK-261104_2153-6 — 403 de BRouter, cause non reproduite

**Friction** : Baptiste reçoit des 403 du serveur public `brouter.de` dans l'éditeur. Un 403 n'était ni relancé ni expliqué : message générique.

**Cause réelle** : Probablement un blocage d'adresse par le serveur public gratuit après trop d'appels (un par segment, plus retour, variantes et secours d'Overpass). Non confirmé : la requête de test complète a été refusée dans la session, seule une requête HEAD a répondu 200 avec CORS ouvert.

**Solution** : Atténuation dans `src/geo/brouter.ts` : message dédié sur 403, sans relance, et cache des 300 derniers itinéraires par URL (sauf `fetch` remplacé par les checks). À confirmer par le corps de la réponse dans l'onglet Réseau (page nginx « 403 Forbidden »). Piste durable : héberger BRouter soi-même (Docker et données de la France, par exemple sur le NAS).
