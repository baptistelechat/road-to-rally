# BLK-20261101150421-7 — Vitesse de mesure variable selon le drapeau de départ

**Friction** : Avant la correction du lag, le même code a donné 23, 25 puis 132 images en 2,3 s. Les passes lentes partaient de la France, les rapides du drapeau laissé par la passe précédente. Cela a faussé une première comparaison.

**Cause réelle** : Inconnue. Peut-être les drapeaux traversés ou un état du navigateur. Le chemin de dessin concerné a depuis été remplacé.

**Solution** : Pas résolu, à creuser seulement si le lag revient. En attendant, toujours partir du même drapeau pour comparer deux mesures.
